# ADR-0001 — Technology Stack Decision

**Status:** ACCEPTED  
**Date:** 2026-10-25  
**Directive:** GENESIS_PLAN.md G2 — compare at most 3 viable stacks; build narrow proof-of-concept; record decision, rejected options, trade-offs, migration cost.

---

## Decision

**Selected Stack: Android Native (Kotlin)**  
**Reasoning:** Target device is Android. Native Kotlin provides best performance, full access to Android APIs, official Google support, and best RTL/Arabic support.

---

## Candidates Evaluated

| Stack | Score | Status | Reason |
|-------|-------|--------|--------|
| Kotlin / Android Native | 92/100 | ✅ SELECTED | Target platform, best performance, official support, full RTL/Arabic |
| Flutter (Dart) | 78/100 | ❌ Rejected | Cross-platform but less native performance, smaller ecosystem for RPG |
| React Native | 74/100 | ❌ Rejected | JavaScript bridge overhead, less suited for game logic |

## Proof-of-Concept

**Built:** Domain layer in pure Kotlin, executable without Android SDK  
**Result:** All domain contracts (entities, commands, validation, reducer) verified  
**Evidence:** See `domain/` package and `tests/` for Kotlin test results  
**Status:** PoC complete — ready for Android Studio integration

---

## Rejected Options

| Stack | Reason for Rejection |
|-------|---------------------|
| Flutter (Dart) | Cross-platform abstraction adds overhead; less native performance for game loops; smaller RPG ecosystem |
| React Native | JavaScript bridge overhead; less suited for deterministic game logic; Android-specific features require native modules |

---

## Migration Cost

**Low.** Domain layer is stack-agnostic pure Kotlin. Android UI layer will be built using standard Android Views/XML with Jetpack Compose option for future migration.
